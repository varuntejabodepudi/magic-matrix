# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, credentials, signing keys, or private user data in a public issue.

Report security concerns privately through the contact options available on the developer's GitHub profile:

https://github.com/varuntejabodepudi

Include the affected component, steps to reproduce, potential impact, and any safe proof-of-concept details. Please allow reasonable time for investigation and remediation before public disclosure.

## Supported versions

There are no published supported release versions documented in this repository yet. This section will be updated when versioned releases are available.
